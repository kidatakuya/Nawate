# 畑ノート

畑ノートは、畑の構造・作物の状態・生育記録を一元管理できる農業向けのWebアプリです。

個体ごとの育成状況を可視化し、畑ごとの使用率や成長段階の変化を簡単に把握できます。家庭菜園から商業農園まで、日々の管理を記録・確認しやすい仕組みを提供します。

## 主な機能

- 畑の登録と構造管理
  - 畑名、畝数、列数、1列あたりの個体数を登録
  - 畑ごとの個体配置を自動生成
- ダッシュボードでの全体可視化
  - 畑ごとの使用状況を一覧表示
  - 空き / 使用中 / 収穫済 / 枯死の状態を可視化
  - 畝×列のヒートマップで状況を確認
- 生育記録の管理
  - 個体ごとの記録追加
  - 日付順に一覧表示
  - 畑で絞り込み検索
- 作物の状態管理
  - 生育中、花期、収穫済、枯死などの状態を把握
  - 個体ごとの詳細ページで状態の確認と編集をサポート

## 技術スタック

- Next.js 16
- React 19
- TypeScript
- Tailwind CSS
- shadcn/ui 風のUIコンポーネント
- Lucide React

## セットアップ

依存関係をインストールします。

```bash
pnpm install
```

## 開発サーバーの起動

```bash
pnpm dev
```

ブラウザで `http://localhost:3000` を開くとアプリを確認できます。

## 本番ビルド

```bash
pnpm build
```

## 本番起動

```bash
pnpm start
```

## 使い方の流れ

1. 畑管理ページで畑を新規登録する
2. 畑の構成（畝数・列数・1列あたりの個体数）を設定する
3. ダッシュボードで各畑の状態を確認する
4. 生育記録ページで個体ごとの成長記録を追加する
5. 状況の変化を追跡し、収穫や管理の判断材料にする

## 補足

このプロジェクトは、Next.js をベースにした個体管理型の農業アプリとして構成されており、UI は日本語で実装されています。今後、データ永続化や認証、CSV 出力などの機能拡張にも対応しやすい構成です。
